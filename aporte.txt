APORTE SOBRE GIT Y GITHUB

1. Comando Git que considero más útil:
Explicación:
Considero que git status es uno de los comandos más útiles porque 
permite comprobar en qué rama estamos trabajando y conocer el estado 
de los archivos, mostrando si existen cambios nuevos, modificados o 
pendientes de registrar.

2. Diferencia entre origin y upstream:
Respuesta:
Origin representa el repositorio personal o Fork del estudiante, 
mientras que upstream representa el repositorio principal del cual 
se realizó el Fork. Origin se utiliza para trabajar y publicar 
nuestros cambios, mientras que upstream permite mantener una 
referencia al repositorio principal.

3. ¿Para qué sirve un Pull Request?
Respuesta:
Un Pull Request sirve para proponer los cambios realizados en una rama 
y solicitar que sean revisados antes de incorporarlos a la rama 
principal de un repositorio.

4. Mencione un error que tuvo durante las prácticas:
Error: Al crear la rama de trabajo escribí por error "feacture-aporte"
en lugar de "feature-aporte".
Solución: Primero regresé a la rama main con git switch main, después 
eliminé la rama creada incorrectamente con git branch -d feacture-aporte 
y finalmente creé la rama correcta utilizando git switch -c feature-aporte.
