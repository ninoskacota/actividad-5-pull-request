APORTE SOBRE GIT Y GITHUB

1. Comando Git que considero más útil: Git status
Explicación: Considero que git status es muy útil porque permite saber qué archivos fueron modificados, cuáles están preparados para ser confirmados y en qué rama me encuentro.

2. Diferencia entre origin y upstream:
Respuesta: Origin es el repositorio remoto que pertenece a mi Fork y donde envío mis cambios. Upstream es el repositorio original del proyecto, desde donde puedo obtener actualizaciones y mantener mi Fork sincronizado.

3. ¿Para qué sirve un Pull Request?
Respuesta: Un Pull Request sirve para proponer cambios realizados en una rama para que sean revisados antes de incorporarlos a otra rama. Permite que otros colaboradores revisen el trabajo, hagan observaciones y aprueben los cambios.
